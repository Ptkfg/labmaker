Sistema para gerenciamento de equipamentos e recursos de um laboratório Maker.

Funcionalidades:
- Visualização de dados por categoria (Gamer, Técnicos, TI, Maker, Notas Fiscais)
- Adição de novos itens diretamente pelo navegador
- Exclusão de itens com atualização automática dos arquivos CSV
- Interface simples e responsiva com HTML + Flask
- Organização modular por rotas e templates

Tecnologias utilizadas:
- Python 
- Flask
- Pandas
- HTML/CSS
- Git + GitHub
